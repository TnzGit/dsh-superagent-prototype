## Receipt state and reconciliation policy

| Receipt | Meaning | Safe operator action |

| `status=sent`, `singleSendAttemptAt` | Synthetic adapter returned accepted result once | Do not replay the old ID |
| `status=pending`, no claim, no `review` | Waits for configured Source, credential or delivery ordering | Check prerequisites; do not bypass allowlist |
| `status=pending`, `review.reason=account_mismatch` or `account_unbound` | Stored context belongs to another/legacy unbound identity | Never adopt the new account for that old receipt |
